# logical-statement-dart
Description:

This activity builds upon my Week 7 Dart programming activity, which introduced the calculation of Body Mass Index (BMI) and the use of variables and conditional statements.

For Week 8, I improved the previous program by incorporating loops, functions, conditional statements, and error handling. The program accepts student information, calculates BMI, determines the student's BMI category, and checks whether the BMI falls within the usual healthy adult BMI range.

It also uses a loop to process multiple student records, a function to calculate BMI, and "try-catch" error handling to manage invalid input. Invalid records are skipped, while valid records are included in the final summary.

# Features
- Conditional Statements: Determine whether a student is an adult and identify the BMI category.
- Loops: Process multiple student records.
- Functions: Calculate BMI and return the result.
- Error Handling: Handle invalid input, such as entering text instead of a number.
- Summary Report: Display the total number of students processed, valid records, invalid records, and students within the usual healthy adult BMI range.
